# Examples

All fixtures are synthetic, deterministic, and content-addressed. They are
generated by `tools/make_fixtures.py` and checked in so the examples run
offline. Each model declares the actual SHA-256 of every file it reads; changing
a fixture without updating the model is a hard error.

Run from the repository root:

```console
cargo run -q -- check examples/position/model.dg
cargo run -q -- report examples/position/model.dg
```

## `position/` — the flagship

A `Vec3`, an `S2C_Position` packet, a function that reads z, a trace
certificate, exact symbol/type evidence, an MT19937 loot RNG, a timing claim, a
uniformity claim, a conflict, security composites, an obligation, and a
refutation. It demonstrates every layer at once.

```console
cargo run -q -- check examples/position/model.dg
cargo run -q -- explain examples/position/model.dg P_reads_vec3_z
cargo run -q -- seal examples/position/model.dg
```

Expected: `P_reads_vec3_z` Deterministic, `P_anchor_exact` and
`P_layout_exact` Exact, `P_recovered` Deterministic, `P_algo` Deterministic,
`C_tick` provisional, `C_loot_uniform` demoted by conflict, and the two security
composites gated on Observational evidence.

## `timing/` — statistical honesty

```console
cargo run -q -- check examples/timing/model.dg
```

A period claim over 6,400 UDP packets: median, CI, coverage, and stationarity.
The claim is capped at Observational and sealed provisionally. A tighter
tolerance is rejected (see `docs/tutorial.md`).

## `rng/` — simulation witnesses

```console
cargo run -q -- check examples/rng/model.dg
```

Algorithm identification from unique constants, a 624-word MT19937 state
re-checked by forward simulation against 64 hashed outputs, and a refutation of
xorshift128 using a deliberate mismatch. `C_predictable` shows the bottleneck:
the algorithm and state are Deterministic, but observability is Observational.

## `loot/` — conflict

```console
cargo run -q -- check examples/loot/model.dg
```

12,000 loot samples look uniform, but the code does `next() % 12`. The kernel
computes the chi-square p-value and the power of the test, seals `biased` at
Deterministic, and demotes the uniform claim to a hypothesis with an explicit
conflict record.

## `port/` — patches

```console
cargo run -q -- port examples/port/model.dg --to b2
```

The b2 fixture moves the reader and loot functions and changes one MT constant.
`port` re-anchors the reader structurally (Heuristic + uniqueness obligation),
marks the algorithm proof stale (missing constant), and drops the recovery
witness (old state does not reproduce the new stream). Nothing is silently
carried.

## `stats/` — samples and mean claims

```console
cargo run -q -- check examples/stats/model.dg
```

`samples` evidence summarizes a locked CSV of mechanics metrics per group
(n, mean, median, sd, 95% CI), and `mean` claims check a claimed mean against
the measured one, its CI, and a power analysis. `C_club_mean` is provisional at
Observational; the tiny-delta claim is recorded as an underpowered hypothesis.

## `coverage/` — coverage claims

```console
cargo run -q -- check examples/coverage/model.dg
```

Five sealed proofs cover opcode ids 1..5 from a locked dataset. `C_cov` seals;
`C_cov82` is a hypothesis because only 5 of the 82 target ids are covered, and
`C_cov6` names the uncovered id 6. DeG counts against the dataset, never on its
own authority.

## `conflicts/` — generic conflicts and decisions

```console
cargo run -q -- check examples/conflicts/model.dg
```

Any two active claims can be declared conflicting. `C_v` resolves inline with
`prefer`; `C_dec` resolves through a hash-pinned human decision file that the
kernel re-hashes at every check. Editing the file breaks the digest, leaves the
conflict unresolved, and blocks sealing.

## `refute/` — generalized refutation

```console
cargo run -q -- check examples/refute/model.dg
```

A `contradicts(ev, rel, [args…])` fact — here carried by an external
certificate's generic facts array — refutes an arbitrary ground atom. The
refutation seals at the evidence's strength, capped by Deterministic.

## Fixtures

| File | Used for |
|---|---|
| `game-b1.bin`, `game-b2.bin` | raw `.text` images with distinct magic prologues, code, and MT constants |
| `session-b1.pcap` | 6,400 position packets at 15.625 ms + jitter; 12,000 loot packets |
| `mt-state-b1.txt`, `mt-observed-b1.txt` | MT19937 state and 64 outputs |
| `mt-state-b2.txt`, `mt-observed-b2.txt` | a different stream for the port example |
| `xs-state.txt` | 4-word xorshift128 state for the refutation |
| `attack-samples.csv` | 240 rows of synthetic per-group mechanic metrics for the stats example |
| `ids.bin`, `ids.txt`, `ids6.txt` | 5-byte opcode image and id universes for coverage/conflict examples |
| `trace.json` | external packet-field → function dataflow certificate |
| `absence.json` | audited `.text` / time-window absence certificate |
| `observability.json` | external connection/window observability certificate |
| `contradicts.json` | external certificate carrying a generic `contradicts` fact |
| `symbols-b1.json` | PDB-like symbols and a Vec3 type |
| `manifest.json` | hashes of everything above |

Regenerate with:

```console
python3 tools/make_fixtures.py
```

The manifest prints the hashes. If you regenerate, update the `sha256:` fields
in the models; the kernel will refuse the stale digests until you do.
